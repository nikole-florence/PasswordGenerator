# PasswordGenerator
Project Title: Password Generator

Purpose of Project: To allow users to customize and generate a password by choosing character set options, and password length, to create a strong and secure password. Unit testing is included to test all features to ensure that they work as expected.

Version: 1.0

Authors: Nikole Florence

User Instructions: Clone the repository to a Python IDE of your choice. Run the PasswordGeneratorNF.py file first, and follow the instructions to create a password, then run the test_generator.py file.
